# 🚀 Авито Агент PRO

Браузерный агент для управления объявлениями на Авито с AI-модерацией.

## ✨ Возможности

- **Очередь на проверку** — все действия AI проходят через тебя перед публикацией
- **Создание объявлений** — AI генерирует заголовок и текст, ты одобряешь
- **Мои объявления** — список активных объявлений с кнопкой поднятия
- **Расписание поднятий** — автоматическое поднятие в 12:00 и 19:30
- **Сообщения покупателей** — AI готовит ответ, ты отправляешь
- **Лог действий** — полная история всего что делал агент

## 🔧 Как использовать

1. Открой `index.html` в браузере
2. Перейди в **Настройки API** → вставь Client ID и Client Secret от [developers.avito.ru](https://developers.avito.ru)
3. Нажми **Подключиться**
4. Всё готово!

## 🔑 Нужные разрешения API

```
items:read items:write messenger:read messenger:write
```

## ⚠️ Важно

Ключи хранятся **только в твоём браузере** (localStorage). Никуда не передаются.
