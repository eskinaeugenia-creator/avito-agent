🔑 Подключение к Авито API
🔒
Ключи хранятся только в твоём браузере. Никуда не передаются и не сохраняются на серверах.
📖 Как получить ключи
1.
Зайди на developers.avito.ru под бизнес-аккаунтом
2.
«Мои приложения» → «Создать приложение»
3.
Выбери разрешения: items:read items:write messenger:read messenger:write
4.
Скопируй Client ID и Client Secret → вставь выше
5.
User ID — зайди на avito.ru → свой профиль → цифры в URL
